# Memória do Projeto - Visão Geral do Projeto

## Objetivo do SaaS
Construir uma plataforma modular, moderna, robusta e multitenant para Gestão de PMEs (Pequenos e Médios Negócios), com arquitetura preparada para recursos e automações inteligentes baseadas em IA (*AI-First*).

## Filosofia de Desenvolvimento
Desenvolvimento incremental, de qualidade premium e cobertura rigorosa de testes automatizados (meta obrigatória de 100% de cobertura). Cada módulo é concluído de ponta a ponta (front-end, back-end, testes, documentação e memória) antes de prosseguir ao próximo.

## Stack de Tecnologia
- **Backend**: Python 3.14+, FastAPI, SQLAlchemy, Alembic, PostgreSQL, Redis, Pytest.
- **Frontend**: React, TS, Vite, TanStack Query, React Router, TailwindCSS.
- **Isolamento**: Docker, Docker Compose.
