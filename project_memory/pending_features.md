# Memória do Projeto - Funcionalidades Pendentes

O roadmap do MVP é composto pelos seguintes módulos subsequentes a serem desenvolvidos de forma totalmente isolada e incremental:

## Módulo 1: Gestão de Estoque & Produtos (Concluído)
- [x] Cadastro de insumos (unidades de medida, categorias, estoque mínimo).
- [x] Cadastro de produtos (preço de venda, margem de contribuição, categoria, status ativo/inativo).
- [x] Ficha Técnica de Produtos (ingredientes/insumos por produto com quantidade e cálculo automático de custo).
- [x] Lançamentos manuais de estoque (entrada, saída, ajustes de inventário).
- [x] Alertas visuais e disparadores para insumos abaixo do estoque mínimo.
- [x] Motor de Consumo Automático (Baixa automática de insumos no estoque quando um produto é vendido, com auditoria vinculada).

## Módulo 2: Gestão de Fornecedores & Compras (Concluído)
- [x] Cadastro de fornecedores e contatos.
- [x] Histórico de compras e relação de produtos fornecidos.
- [x] Avaliação de prazos, preços e qualidade de fornecedores.

## Módulo 3: Gestão de Colaboradores Avançada & Escalas (Concluído)
- [x] Controle operacional de escalas de turnos por colaborador.
- [x] Trocas e aprovações de turnos de trabalho.
- [x] Jornada, controle de ausências e férias.

## Módulo 4: Dashboards e IA Analytics (AI-First) (Concluído)
- [x] Dashboards consolidados de custos, giro de estoque, eficiência e ticket médio.
- [x] Motor de IA para previsão de consumo e ruptura de estoque.
- [x] Assistente IA para sugestão automatizada de ordens de compras com base no giro histórico.
